# Product Specification

## 1. 목적
부모가 아이와 같이 놀면서 수학을 했던 경험을 AI 친구와의 상호작용으로 확장한다. 목표는 문제집을 게임처럼 포장하는 것이 아니라, 놀이 과정 자체에서 수학 행동이 발생하게 하는 것이다.

## 2. 대상
- 최종: 초등학교 1~6학년
- 첫 MVP: 초등학교 1학년, 10 이하 덧셈

## 3. 아이 경험
아이에게는 `공부 시작`보다 `수키랑 놀기`가 먼저 보인다.

### 네 가지 핵심 놀이
1. **SUKI_ASKS**: 수키가 문제를 내고 아이가 해결
2. **CHILD_TEACHES**: 아이가 문제를 만들고 수키에게 출제
3. **COOP_SOLVE**: 아이와 수키가 공동으로 해결
4. **FIND_SUKI_ERROR**: 수키가 의도적으로 안전하게 생성된 오답을 제시하고 아이가 오류 발견

## 4. 오답 UX
큰 X, 벌점, 별 차감을 기본적으로 사용하지 않는다.
- 1차: "어? 우리 답이 다르네?"
- 2차: 생각 유도 힌트
- 3차: 그림/블록 시각화
- 4차: 수키와 일부를 함께 해결
- 필요 시 쉬운 문제로 성공 후 원래 난이도 복귀

## 5. 적응형 난이도
초기에는 규칙 기반.
- 연속 성공 + 빠른 해결 → 난이도 상승
- 긴 정체 → 힌트 제안
- 반복 오류 → 표현 방식 변경
- 너무 쉬움 → 도전 문제
- 피로 신호 → 짧은 보너스/휴식 후 종료 제안

## 6. 문제 표현
- 숫자식
- 그림 세기
- 이야기 문제
- 선택형
- 드래그/블록
- 빈칸 채우기
- 보물/미션형

## 7. 보상
### 별
놀이 중 획득하는 즉각 보상. 틀렸다고 차감하지 않는다.
- 익숙한 문제 성공: 1
- 적정 난이도 성공: 2
- 도전 문제 성공: 3
- 수키 오류 발견/설명: 보너스 가능

### XP
소비되지 않는 누적 성장값. 레벨 계산에 사용.

### 레벨
MVP는 Lv.1~10. 향후 장기 레벨 체계 확장.

### 해금
별/레벨에 따라 보물상자, 새로운 놀이, 꾸미기 등을 해금한다.

## 8. 경쟁
향후 주간 리그를 제공한다.
- 실명 대신 닉네임/아바타
- 공개 전체 순위만 강조하지 않고 친구/가족/소규모 리그 고려
- 쉬운 문제 무한 반복으로 랭킹을 올리는 것을 방지
- 적정/도전 난이도 보상 가중

## 9. 수키 AI 상태
12개 기본 상태를 UI/애니메이션에 연결한다. 자세한 값은 `src/data/suki-states.json` 참조.

## 10. 아이 상태 추정
- ENGAGED
- THINKING
- STUCK
- REPEATED_ERROR
- TOO_EASY
- FATIGUE
- MASTERY

## 11. 기록 데이터
최소 기록 필드:
- concept_id
- difficulty
- game_mode
- representation
- response_time_ms
- attempts
- hint_level
- self_corrected
- correct
- completed

## 12. 부모 화면
아이 화면과 분리한다.
- 활동 시간
- 개념별 이해 추정
- 혼자 해결 / 힌트 후 해결
- 어려움을 보인 표현/유형
- 다음 추천 활동

## 13. 안전 원칙
- 아동 개인정보 최소 수집
- 수키의 기억은 우선 학습 활동 중심
- 자유대화는 제한된 수학놀이 맥락 중심
- 수학 정답은 LLM이 단독 결정하지 않음
