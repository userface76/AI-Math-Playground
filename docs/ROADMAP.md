# Roadmap

## Phase 0 — 현재
- 제품 철학 확정
- 수키 3D 기준 캐릭터/감정 컨셉 제작
- MVP 게임 구조 정의
- 별/XP/레벨 구조 정의

## Phase 1 — Clickable MVP
- 모바일 UI
- 초1 10 이하 덧셈
- 4가지 놀이 모드
- 힌트 3단계
- 별/XP/Lv.1~10
- 보물상자
- 로컬 학습기록

## Phase 2 — Child Test
핵심 검증:
- 스스로 시작하는가
- 5~10분 지속하는가
- 수키에게 문제 내기를 좋아하는가
- 힌트 후 다시 시도하는가
- 종료 후 "한 번 더"가 나오는가

## Phase 3 — Backend
- 사용자/보호자 계정
- 학습 기록 DB
- 수키 학습 기억
- 부모 리포트
- 다중 기기 동기화

## Phase 4 — AI
- 안전한 수학놀이 대화
- 개인별 도움 수준 조절
- 표현 방식 추천
- 학습 데이터 기반 다음 미션 선택

## Phase 5 — Curriculum Expansion
- 1학년 전체
- 2~6학년 순차 확장
- 수와 연산, 도형, 측정, 규칙, 분수/소수, 비와 비율 등 인터랙션 모듈

## Phase 6 — Social
- 주간 리그
- 친구/가족 리그
- 닉네임/아바타 중심
- 부정 반복/쉬운 문제 파밍 방지

## Approval gates
다음 시점에는 프로젝트 소유자 확인/승인이 필요하다.
1. 정식 앱/캐릭터 이름 확정
2. GitHub 저장소 생성 또는 기존 저장소 선택
3. 백엔드/AI 외부 서비스 선택 및 비용 발생
4. 로그인/아동 데이터 정책 확정
5. 실제 공개 배포
