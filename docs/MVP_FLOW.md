# MVP v0.1 Play Flow

## Session goal
초1 `10 이하 덧셈`을 약 5~10분 동안 놀이로 경험한다.

## Flow
1. **Home** — 수키가 등장: "나랑 놀래?"
2. **Warm-up** — 그림으로 매우 쉬운 덧셈
3. **Suki asks** — 수키가 별/과일 문제 출제
4. **Child teaches** — 아이가 두 묶음을 만들어 수키에게 출제
5. **Find Suki error** — 수키의 안전하게 생성된 실수 찾기
6. **Co-op** — 수키와 블록을 같이 움직여 해결
7. **Treasure mission** — 예: `4 + □ = 10`
8. **Adaptive final mission** — 현재 수준에 따라 자동 선택
9. **Reward** — 별/XP/레벨 진행
10. **Finish** — 점수 대신 오늘의 발견을 보여주고 종료

## Example turn
문제 데이터: `4 + 3 = 7`

### SUKI_ASKS
"별 4개를 찾았는데 3개가 더 왔어. 모두 몇 개일까?"

### CHILD_TEACHES
아이가 4개와 3개 묶음을 만들고 수키가 답을 선택한다.

### FIND_SUKI_ERROR
수학 엔진이 정답 7을 확정한 뒤, 오답 후보(6 또는 8)를 수키에게 제공한다. 수키가 임의 계산으로 오답을 생성하지 않는다.

### COOP_SOLVE
수키가 4까지 세고 아이가 5, 6, 7을 완성한다.

## Hint ladder
- H0: 기다림
- H1: 언어 힌트
- H2: 그림/블록 시각화
- H3: 수키와 공동 풀이

## End screen
아이에게:
- 오늘 모은 별
- 레벨 진행도
- 발견/협동/가르치기 배지

부모에게:
- 실제 정답률
- 평균 반응시간
- 힌트 의존도
- 다음 추천 개념
