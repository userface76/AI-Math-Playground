# 1000단계 러닝앱 기획서 1차

## 1. 프로젝트 개요
가칭: **RUN 1000 / 런천**
목표: 30~90초 안에 한 판을 끝낼 수 있는 캐주얼 러닝 미니게임. 남/여 캐릭터를 선택하고, 좌우 이동으로 게이트와 장애물을 통과하며 1~1000 스테이지를 진행한다.

## 2. 핵심 플레이
- 3레인 자동 전진 러닝
- 좌/우 버튼 또는 스와이프로 레인 변경
- 게이트: +2, +5, ×2, ×3 등으로 파워/동료 수 증가
- 위험 게이트: -3, ÷2 등은 회피
- 장애물 충돌 시 파워 감소
- 스테이지 끝의 벽/보스 수치보다 파워가 높으면 클리어
- 클리어 후 다음 스테이지 자동 해금

## 3. 캐릭터
- 남자 러너 / 여자 러너 2종으로 시작
- 2차: 속도형, 점프형, 보상형 등 스킨/특성 캐릭터 확장
- 타 게임의 캐릭터를 복제하지 않고 자체 디자인 사용

## 4. 1000 스테이지 구조
- 10개 월드 × 100 스테이지 = 1000단계
- 월드 예시: 초원, 도시, 사막, 얼음, 정글, 기계도시, 용암, 바다, 우주, 챔피언
- 1~50: 튜토리얼
- 51~150: 게이트 선택 강화
- 151~300: 장애물 추가
- 301~500: 속도/패턴 변화
- 501~700: 적군/함정
- 701~900: 특수 스테이지
- 901~1000: 보스/챔피언

## 5. 1차 프로토타입 범위
- 남/여 캐릭터 선택
- 3레인 이동
- + / × 게이트
- 장애물
- 파워 수치
- 스테이지 1~1000 표기
- 골인 보스/벽 판정
- 승리/실패 및 재도전
- 로컬 진행 저장

## 6. 2차 확장
- 월드별 배경
- 캐릭터 스킨
- 코인/별
- 일일 미션
- 보스전
- 업그레이드
- 사운드/진동
- 랭킹
- 스테이지 자동 생성 규칙 고도화

## 7. 기술
- 1차: HTML5 Canvas + Vanilla JavaScript
- 모바일 우선 터치/스와이프
- 정적 배포 가능
- 향후 Phaser/Capacitor 또는 Unity 전환 가능
